# Проверка темы по списку преподавателей

Источник: пользовательский файл `Titles of Diploma Projects 2026-27 (for Students)(1).xlsx`, проверка 14 октября 2026.

Проверены 50 листов, извлечена 291 пронумерованная запись темы. Выполнены нормализованное сравнение названий и поиск ключевых слов по русским и английским формулировкам. Точного совпадения с нашей темой не обнаружено. Это проверка предоставленной версии списка, а не официальное одобрение университета и не доказательство мировой уникальности.
