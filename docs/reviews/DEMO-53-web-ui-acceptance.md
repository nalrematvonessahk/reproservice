## Прогон на стенде docker compose

Сценарий `multi-fault-demo`, шаги по кнопкам интерфейса. Загрузка и валидация, Start run: `ORIGINAL_FAILURE` (`payment_exactly_once violated: expected 1, actual 2`), в таймлайне 4 события; у `fault/dropped` в деталях видны вмешательство `fault-1` и родительское событие. Reduce (ddmin): `stop_reason: minimal`, принят `fault-1`, 9 запусков из 100 (6 подтверждающих). Сравнение: сокращённый набор, 3 повтора: `ORIGINAL_FAILURE 3/3`; пустой набор, 3 повтора: `PASS 3/3` с оговоркой «не доказательство», слов «fixed» и «исправлено» нет; отмена сравнения на 5 повторах оставила 2 записанных запуска без вывода («2 run(s) is not enough»). Отмена сокращения (sequential): `stop_reason: CANCELLED`, 8 запусков, набор помечен «1-minimal: no -- the search did not finish». Экспорт: файл (предпросмотр) содержит `events`, `reduction`, `run`, `scenario`, `schema_version`, 4 события, `outcome = ORIGINAL_FAILURE`, строк `authorization`, `cookie`, `set-cookie` нет; предпросмотр доступен с клавиатуры. Скачивание файла кнопкой Download file здесь не проверялось (проверено на стенде, запущенном напрямую).

axe-core на этой странице (окно шириной 618 px) нашёл ещё один дефект: подписи `dt` в нейтральном блоке результата сокращения (он виден при отмене) ниже 4.5:1. Исправлено в `task-demo-56`, тест на контраст подписей добавлен.

## Прогон на живом стенде без Docker

Сценарий `multi-fault-demo` в настоящем Chrome против живого контроллера, шаги по кнопкам интерфейса: загрузка и валидация сценария, Start run, `ORIGINAL_FAILURE` примерно за 2 с, в таймлайне 4 события без дублей, событие `fault/dropped` раскрывает родительское событие, Reduce (ddmin): `stop_reason: minimal`, 9 запусков из 100 (6 подтверждающих), Export JSON и Download file. Время всего сценария около 4 с: это работа интерфейса, а не результат пилота NFR05, так как проходил её автор проверки. На 390 и 1280 px горизонтальной прокрутки нет, axe-core без нарушений, HTTP-ошибок нет. Не прогонялось: сравнение версий с повторами (FR11) и отмена сокращения, их проверял Aldiyar.

Этот прогон нашёл ещё один дефект, которого не было на замоканных данных: серый вторичный текст на выбранной строке таймлайна ниже 4.5:1 (axe, `color-contrast`). Исправлено в `task-demo-56`, добавлены тесты на коэффициент контраста.
