# Макет и сценарии использования

Открыть prototype/index.html в браузере без установки. Все числа и события синтетические; backend не подключён.

Основной путь: выбрать вмешательство → «Запустить макет» → открыть событие → увидеть нарушение → «Сократить» → сравнить с исправленной версией → экспортировать демонстрационный JSON. «Сбросить» возвращает начальное состояние. До запуска кнопки дальнейших действий недоступны.

UX-проверка: дать пользователю задачу найти причину повторной оплаты, сократить сценарий и экспортировать отчёт. Не объяснять кнопки заранее. Записать время, ошибки, непонятные формулировки и обращения за помощью. Проверить клавиатуру, контраст, перенос текста и окно 390 px. Пять реальных участников и их результаты пока отсутствуют.

Состояния будущего продукта: пустой список; валидация; запуск; отмена; исходное нарушение; другой сбой; инфраструктурная ошибка; неприменимый сценарий; бюджет исчерпан. Макет иллюстрирует основной путь, а не реализует все состояния продукта.
