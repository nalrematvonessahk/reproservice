# Что требует внешнего участия

Эти пункты нельзя заменить локальными файлами или действиями ассистента без доступа.

| Пункт | Уже подготовлено | Необходимый вход | Проверяемый результат |
|---|---|---|---|
| GitHub | Структура, README, PR-шаблон, правила review | Подключить GitHub; выбрать владельца проекта; имена аккаунтов команды | Реальный URL, доступы и PR |
| YouTrack | 22 задачи, владельцы, сроки, dry-run импорта | URL сервера, существующий проект и доступ через разрешённое подключение | Реальные IDs и custom fields |
| Интервью | Вопросы, согласие, форма, критерии синтеза | 3–5 реальных собеседников и их ответы | Обезличенные записи с датами |
| Руководитель | Пакет, повестка, форма замечаний | Реальная обратная связь Arailym Orazova | Замечания → изменения → подтверждение |
| Личный вклад | Распределение и review workflow | Работа каждого студента со своего аккаунта | Подлинные коммиты и review |
| Браузерная проверка | HTML и проверка JS-переходов | Chrome/Edge с открытым prototype/index.html | Ручная проверка отображения и экспорта |

Пароли и токены не вставлять в чат или Git. Для подключения использовать интерфейс интеграции; для локального API-импорта — переменные окружения на своей машине.
